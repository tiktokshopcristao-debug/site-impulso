# SITE IMPULSO

Landing page para a marca Impulso, criada para deploy em GitHub + Vercel.

## Como visualizar localmente

Abra a pasta do projeto e execute qualquer servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Deploy

O projeto é estático e funciona diretamente em ambientes como Vercel.
